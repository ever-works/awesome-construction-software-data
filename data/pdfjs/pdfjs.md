## Overview

PDF.js is an open-source PDF viewer/editor built with its own Rust engine for fast rendering. It is a JavaScript library that enables PDF documents to be rendered in web browsers without plugins.

## Features

- PDF rendering in web browsers
- Rust-based rendering engine
- JavaScript library
- No browser plugins required
- Open source

## Pricing

Free and open-source. Repository: https://github.com/mozilla/pdf.js

## Deployment

Web-based (JavaScript library).
