## Overview

BIMserver is an open-source BIM server platform that provides centralized storage and management of IFC-based building information models. It enables collaborative workflows by allowing multiple stakeholders to access and work with BIM data in a shared environment.

## Features

- IFC model storage and management
- Centralized BIM data repository
- Collaborative access for project stakeholders
- Version control for building models
- Web-based client interface
- REST API for integration

## Pricing

Free and open-source. Repository: https://github.com/opensourceBIM/BIMserver

## Deployment

Self-hosted server.
