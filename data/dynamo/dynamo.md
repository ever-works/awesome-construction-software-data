## Overview

Dynamo is an open-source graphical programming environment for computational design and automation. It is commonly used with Autodesk Revit and other BIM authoring tools to create custom workflows, automate tasks, and perform generative design.

## Features

- Visual programming interface
- Computational design and automation
- Integration with Autodesk Revit
- Custom node creation
- Data import/export from multiple sources
- Generative design capabilities

## Pricing

Free and open-source. Repository: https://github.com/DynamoDS/Dynamo

## Deployment

Desktop application (plug-in for Revit and other hosts).
