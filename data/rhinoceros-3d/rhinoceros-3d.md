## Overview

Rhinoceros 3D (Rhino) is a 3D computer graphics and CAD application used for architectural design, industrial design, and BIM workflows, supporting NURBS modeling and extensive plugin ecosystems including Grasshopper for parametric design.

## Features

- NURBS-based 3D modeling
- Grasshopper visual programming for parametric design
- Support for multiple file formats including DWG, DXF, OBJ, STL
- Rendering and visualization
- Plugin ecosystem for BIM and analysis
- Scripting with Python and RhinoScript
- 2D drafting and documentation
