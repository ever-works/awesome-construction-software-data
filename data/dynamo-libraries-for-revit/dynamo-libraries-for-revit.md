## Overview

Dynamo Libraries for Revit is an open-source visual programming platform for computational design and automation within Autodesk Revit. It enables users to create custom scripts, automate repetitive tasks, and perform generative design workflows.

## Features

- Visual programming for Revit
- Computational design
- Task automation
- Generative design
- C# libraries
- Revit API integration

## Pricing

Free and open-source. Repository: https://github.com/DynamoDS/Dynamo

## Deployment

Desktop plug-in for Autodesk Revit.
