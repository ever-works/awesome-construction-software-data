## Overview

IFC.js is the official IFC Loader for Three.js, an open-source JavaScript library that enables loading and rendering Industry Foundation Classes (IFC) BIM models in web browsers using Three.js.

## Features

- Load IFC files in the browser via Three.js
- Web-based BIM model visualization
- Open-source JavaScript library
- Official IFC loader for the Three.js ecosystem

## Pricing

Free and open-source.

## Deployment

Web-based (browser), client-side JavaScript library.
