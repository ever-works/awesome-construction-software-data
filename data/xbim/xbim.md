## Overview

xBIM is an open-source .NET library for working with IFC (Industry Foundation Classes) building information models, enabling developers to create BIM applications with C# and .NET.

## Features

- IFC file reading and writing for .NET applications
- IFC2x3 and IFC4 schema support
- Geometry engine for visualizing IFC models
- C# API for BIM application development
- Cross-platform .NET support
- Open-source under LGPL license
- Active community and documentation
