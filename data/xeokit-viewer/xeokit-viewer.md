## Overview

xeokit Viewer is a JavaScript-based 3D viewer built with the xeokit SDK, designed for IFC, BIM, and point cloud visualization in AEC and GIS applications. It provides double precision global coordinates for accurate real-world positioning.

## Features

- IFC and BIM model viewing
- Point cloud visualization
- Double precision global coordinates
- AEC and GIS application support
- WebGL-based rendering
- JavaScript SDK

## Pricing

Free and open-source. Repository: https://github.com/xeokit/xeokit-sdk

## Deployment

Web-based (JavaScript library).
