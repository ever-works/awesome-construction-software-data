## Overview

iTwin.js is an open-source JavaScript/TypeScript library monorepo from Bentley Systems for developing iTwin (digital twin) applications. It enables developers to build web, desktop, and mobile applications that visualize and interact with infrastructure, BIM, and geospatial data.

## Features

- Digital twin application development
- BIM and infrastructure data visualization
- Web, desktop, and mobile application support
- TypeScript/JavaScript libraries
- iModel (iTwin) data access
- Geospatial and engineering data integration

## Pricing

Free and open-source. Repository: https://github.com/iTwin/itwin-js

## Deployment

Web-based, desktop, and mobile (JavaScript/TypeScript libraries).
