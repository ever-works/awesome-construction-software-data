## Overview

Autodesk Forge is a cloud-based developer platform offering APIs and services for integrating design, engineering, and construction data into custom applications. It supports BIM data workflows including model viewing, data management, and design automation.

## Features

- View and Derivative API for translating and viewing 2D and 3D models
- Data Management API for accessing and managing design data
- Model Derivative API for extracting model geometry and properties
- Design Automation API for batch processing of design files
- BIM 360 API for connecting to construction management data
- Webhooks for real-time event notifications
- OAuth 2.0 authentication
- SDKs for multiple programming languages

## Pricing

Pay-as-you-go model using credits consumed per API transaction. Free tier available for development and testing.

## Deployment

Cloud-hosted platform accessed via REST APIs.
