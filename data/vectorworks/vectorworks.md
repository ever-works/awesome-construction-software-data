## Overview

Vectorworks is a BIM and CAD software solution for architects, landscape architects, and entertainment designers, supporting 2D drafting, 3D modeling, and building information modeling workflows across multiple design disciplines.

## Features

- 2D drafting and 3D modeling
- BIM workflows with IFC support
- Architectural design and documentation
- Landscape architecture tools
- Entertainment design tools
- Rendering and visualization
- Collaboration and file sharing

## Pricing

Paid commercial software with perpetual license and subscription options available through Vectorworks.
