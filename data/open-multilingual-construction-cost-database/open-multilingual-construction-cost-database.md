## Overview

Open multilingual construction cost database for AI Agents containing 55K+ work items, 27K+ resources, and coverage of 30 regions. Provides semantic search via Qdrant vector database.

## Features

- 55K+ work items
- 27K+ resources
- 30 regions
- Multilingual support
- Semantic search via Qdrant vector database
- AI agent focused

## Pricing

Free and open-source.

## Deployment

Web-based, HTML.
