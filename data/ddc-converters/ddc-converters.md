## Overview

DDC Converters 2.0 is a suite of file conversion tools for AEC data formats. It converts RVT/RFA to GLB, IFC4, and JSONL; IFC to Excel; and DWG to Excel, DXF, and SVG. Available as offline CLI, desktop apps, n8n workflows, and AI-agent instructions.

## Features

- RVT/RFA to GLB, IFC4, JSONL conversion
- IFC to Excel conversion
- DWG to Excel, DXF, SVG conversion
- Offline CLI
- Desktop applications
- n8n workflows
- AI-agent instructions
