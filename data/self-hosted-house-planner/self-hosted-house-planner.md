## Overview

Self-hosted house planner featuring true-scale 2D floor plans, 3D visualization, satellite map overlay, sewer, electrical, water, and underfloor heating with calculations, plus priced bill of materials. Built with React + PHP, no database required.

## Features

- True-scale 2D floor plans
- 3D visualization
- Satellite map overlay
- Sewer, electrical, water design
- Underfloor heating with calculations
- Priced bill of materials
- React + PHP stack
- No database required
- Self-hosted

## Pricing

Free and open-source.

## Deployment

Self-hosted, React + PHP, no database.
