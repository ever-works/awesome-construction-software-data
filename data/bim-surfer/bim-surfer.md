## Overview

BIM Surfer is a WebGL-based viewer for IFC (Industry Foundation Classes) building information models. It enables web-based visualization of BIM data without requiring specialized desktop software.

## Features

- IFC model viewing
- WebGL-based rendering
- Web browser-based
- Open source
- JavaScript

## Pricing

Free and open-source. Repository: https://github.com/IfcOpenShell/BIMsurfer

## Deployment

Web-based.
