## Overview

SketchUp is a 3D modeling software used for architectural design, interior design, and construction visualization, offering intuitive modeling tools and integration with BIM workflows through extensions and IFC support.

## Features

- 3D modeling and visualization
- Push-pull modeling interface
- Extension Warehouse for plugins
- IFC import/export support
- LayOut for 2D documentation
- 3D Warehouse model library
- Rendering and VR/AR support

## Pricing

Freemium model with free web-based version (SketchUp Free) and paid Pro, Studio, and subscription plans.
